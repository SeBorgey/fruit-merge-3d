# fruit-merge-3d

3D-игра на Unity (клон Suika Game / Watermelon Game), оптимизированная для мобильных платформ.

## Особенности
- Реалистичная физика падения и объединения 3D-фруктов.
- Система локального сохранения рекордов и настроек.
- Поддержка локализации интерфейса (русский/английский).
- Интеграция с онлайн-таблицей лидеров через SDK Dan.Main (LootLocker).
